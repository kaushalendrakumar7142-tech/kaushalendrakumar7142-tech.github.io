Privacy Policy: Abstractly Channel Manager

Last updated: 21 November 2026

Who uses this app

Abstractly Channel Manager is a private tool used only by the owner of the Abstractly YouTube channel to manage their own channel. It is not offered to the public.

YouTube API Services

This app uses the YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy.

What data the app accesses

With the channel owner's permission, the app accesses the owner's own YouTube channel data through the YouTube Data API and the YouTube Analytics API. That data is:

  • channel details and settings
  • videos, playlists and their metadata
  • comments on the channel's videos
  • channel and video statistics

It does not access any other Google account data.

How the data is used

The data is used only to carry out actions the channel owner requests: uploading and editing videos, managing playlists and comments, and showing statistics. It is not sold, shared with third parties, or used for advertising.

Storage

An OAuth token that authorizes access to the channel is stored on a private server controlled by the channel owner. API responses are processed on request and are not kept as a separate database.

Revoking access

Access can be revoked at any time from the Google Account permissions page. Once access is revoked, the app can no longer reach the channel.

Contact

Contact the owner through the GitHub profile that hosts this page.
